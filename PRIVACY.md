# 隐私政策 / Privacy Policy

**Acrylic Wallpaper 不收集、不传输任何用户数据。**

- 不收集浏览历史、网址、页面内容、截图或个人信息。
- 扩展不发起任何网络请求；壁纸、图标和代码全部打包在扩展内部。
- 设置（总开关、强度、明暗模式、站点禁用名单）通过浏览器自带的 `chrome.storage.sync` 保存在本地，并由浏览器自身的账号同步机制同步；开发者无法读取。
- 扩展只在页面内插入样式和一层背景元素，不修改页面内容，不读取页面文本。

如未来引入任何数据收集，会先更新本文件并在扩展更新说明中注明。

最后更新：2026-11-26

# Privacy Policy (English)

**Acrylic Wallpaper collects and transmits no user data.**

- No browsing history, URLs, page content, screenshots, or personal information is collected.
- The extension makes no network requests. The wallpaper, icons, and code are all bundled locally.
- Settings (enabled, strength, theme mode, disabled hosts) are stored with the browser's own `chrome.storage.sync` and synced by the browser account; the developer cannot read them.
- The extension only injects a style sheet and one background element into pages. It does not modify page content or read page text.

Any future data collection would be documented here first and called out in the release notes.

Last updated: 2026-11-26
